# 交互逻辑修订（branch `fix/human-interaction`）

> 本文只记"**原来为什么不顺手**"与"**现在怎么改**"，不写营销话术。
> 每条都对应现场能感知到的动作，改完都补了回归测试。

---

## 1. 拖动点位：三步 → 一步

**原来**：右键点 → 「拖动点位」 → 再点地图上的目标位置。
三步，中途不能反悔，也看不到拖动过程。任何绘图软件都不这么做
（奥维、Bigemap、QGIS 都是按住就拖）。

**现在**：按住已有点直接拖，实时跟手，松手落位。

实现要点（`lib/ui/map/map_canvas.dart`）：

- 用 flutter_map 的 `onPointerDown/Move/Up` 做命中判定，**不**在 Marker 上
  套 `GestureDetector`——那会和地图平移抢事件；
- 位移超过 4px 才进入拖拽态，否则仍算单击（避免手抖把点拖跑）；
- 拖拽期间 `InteractiveFlag.drag` 自动摘掉，否则鼠标一动地图跟着跑、
  杆位站不住；
- 桌面壳 `enablePointDrag: true`，移动端保持 false（单指拖动必须留给平移）。

## 2. 撤销：一次拖拽会灌满整个撤销栈

**原来**：拖动/编辑时逐帧压快照。一次拖拽能压进去几十份快照，
Ctrl+Z 按二十次也回不到拖之前——用户看到的是"撤销像坏了"。

**现在**：**懒压 + 整段只压一次**（`app_state.dart`）：

```dart
beginDragLabel(l)  // 只记录状态，不压快照
dragLabelTo(l,..)  // 首次真正改坐标时才 pushUndoSnapshot()，之后复用
endDragLabel()     // 没移动过 → 不落盘、不留快照
```

---

## 3. 撤销深度：20 → 200

**原来**：`_undoLimit = 20`。一条 30 杆的杆路，撤到第 20 步就再也回不去。
现场最不能接受的失效方式就是"改错了撤不回来"。

**现在**：200 步（`_undoLimit = 200`）。

---

## 4. Esc：从"什么都不做"变成"退出当前工具"

**原来**：打点态下按 Esc 只弹一句「当前没有可取消的操作」。
用户被卡在打点态里——想滚轮看看别处，一点又落一个新点。

**现在**：Esc 在 `AppMode.edit` 下**结束打点回到浏览态**，草稿完整保留
（`workspace_page.dart` → `_escape`）。清空草稿另有专门入口。

---

## 5. 新点序号：`length + 1` → `max(seq) + 1`

**原来**：序号按列表长度算。3 个点删掉中间那个，新点又是 3 →
两点同号。出图体检报「链内序号不连续」，但怎么查都查不出原因。

**现在**：`_seqAfter()` 取现有最大序号 + 1，删点/撤销后都不会撞号。

---

## 6. 两条丢撤销的路径

`markHere()`（我在这）与 `startRouteFrom()`（从此点续画）都会往 `labels`
插点，但**都没压快照** —— 插进去的点撤不回来。现已补上。

---

## 7. 相邻段距失效判据

**原来**：按数组下标判断"相邻"。
- 下标相邻但在不同杆路（不同 `lineGroupId`）→ 误伤别的线；
- 同线组但中间隔着独立个体（箱体/文字不参与连线）→ 该失效的没失效。

**现在**：按 `lineGroupId` 判断（`_invalidateNeighborDist`）。

---

## 8. 标记编号重启后撞名

**原来**：`_markCount` 是进程内计数器，重启归零。重启后再标记，
名字又从「标记1」开始，和收藏里已有的撞名。

**现在**：`_appendToMarkBook` 用收藏内已有的最大「标记N」把计数器顶上去
（`_maxMarkIndex`）。

---

## 9. 图例库符号在移动端的显示

图例库符号名较长（「新建壁挂光缆交接箱」），62px 的格子放不下旧字号。
已改为 9.5 号字 + `ellipsis`，并且**优先显示名称**（用户按名字找，
不按 gl001 找）。
